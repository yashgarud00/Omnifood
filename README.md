Omnifood Website
Omnifood is an AI-powered food subscription service that delivers healthy meals to your door every day. This project contains both the frontend website and a simple backend server for demo purposes.

Features
Responsive, modern landing page for Omnifood
Interactive navigation and smooth scrolling
Sticky header and mobile navigation
Customer testimonials and photo gallery
Pricing plans and feature highlights
"Try for free" sign-up form with backend integration
Progressive Web App (PWA) manifest

Project Structure:
backend/
  package.json
  server.js
frontend/
  index.html

  css/
    general.css
    style.css
    queries.css
  js/
    script.js
  img/
    ... (images for meals, customers, gallery, logos, etc.)

Getting Started
Prerequisites
  Node.js installed
  
Installation
1. Install backend dependencies:
      cd backend
      npm install
2. Start the server:
      npm start
3. Open the website:
    Visit http://localhost:3000 in your browser.

Usage:
    Browse the landing page to learn about Omnifood.
    Try the sign-up form in the "Get your first meal for free!" section.
    The backend stores sign-ups in memory and logs them to the console.
    
Customization:
    Edit content.md for website content.
    Update images in img as needed.
    Modify styles in css for branding.
